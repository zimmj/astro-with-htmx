This file exists as a frontmatter reference. Copy it when starting a new piece, then delete or update the fields:

- `format`: one of `essay`, `observation`, `note`, `question`
- `pillar`: one of `technology`, `travel`, `productivity`, `philosophy`, `culture`
- `tags`: freeform, for finer-grained filtering than `pillar`
- `updatedDate`: add only when revising a published, living document
- `location`: optional, omit if not tied to a specific place
- `draft: true` keeps a post out of listings until it's ready
